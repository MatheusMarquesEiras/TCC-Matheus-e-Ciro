# Artigo em LaTeX (template IEEE Access)

`main.tex` é o artigo do TCC (versão em português) preenchido no template LaTeX
oficial da IEEE Access (`ACCESS_latex_template_20260513`). O zip
`Artigo IEEE Access - PT (Overleaf).zip`, no repositório privado, tem tudo o que o Overleaf precisa.

No Overleaf: **New Project → Upload Project →** escolher o zip. O compilador é o
padrão (pdfLaTeX); o arquivo principal é `main.tex`.

O template da IEEE (classe, fontes e logos) não está neste repositório público; baixe-o em
https://ieeeaccess.ieee.org/authors/preparing-your-article/ e copie os arquivos para esta pasta.
